# Public technical references

- [PS2Recomp](https://github.com/ran-j/PS2Recomp) - local pinned recompilation/runtime foundation.
- [ps2tek](https://psi-rockin.github.io/ps2tek/) - public hardware reference; verify individual contracts with tests.
- [PS2SDK](https://github.com/ps2dev/ps2sdk) - open homebrew interfaces, including controller structures.
- [Ghidra Emotion Engine Reloaded](https://github.com/chaoticgd/ghidra-emotionengine-reloaded) - R5900-aware analysis support.
- [Chaos Compiler Collection](https://github.com/chaoticgd/ccc) - ELF and symbol analysis references.
- [ECMA-119](https://ecma-international.org/publications-and-standards/standards/ecma-119/) - disc filesystem format reference for the bounded ISO reader.
- [Manhunt Toolkit](https://github.com/Sor3nt/manhunt-toolkit) - asset-format research reference; not a complete native engine.

Links are technical starting points, not claims of universal compatibility. No manuals, leaked SDKs or game assets are bundled.
